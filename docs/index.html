PHP · SDL · WebGL 2

A 2D game engine, written in PHP.

Load Tiled worlds, build entities from components, and run surface-based platforming in the browser.

The PHP runtime downloads when you press Run PHP.

Keyboard: arrows / WASD move · Space / Z jump · Down + X charge dash · Hold X in air for drop dash · Jump again to glide or fly · Up / Down climb · R reset · P / Escape pause. Stop before switching scenes. Streaming world: arrows/WASD pan, R returns to the start, X retries failed downloads.

Gamepad: left stick / D-pad move · A / Cross jump · B / Circle dash · Start / Options pause · Back / Select reset. B / Circle retries downloads in Streaming world. Click the canvas and press a gamepad button to connect. Sticks use a 20% dead zone with proportional movement.

The game pauses in a hidden tab. If the browser releases WebGL, it restores graphics when the context returns and keeps the current game state. Release held gamepad buttons and center the sticks after returning to the game.

Start locally

git clone https://github.com/seanmorris/php-wasm-engine.git
cd php-wasm-engine
npm ci
npm start

The webpack dev server reloads the page when demo files, PHP sources, shaders, or assets change. Press Run PHP after each reload.

The demo uses a pinned build of php-sdl-wasm. JavaScript loads PHP and mounts files; PHP handles input, simulation, asset parsing, and GPU calls.

Stream nearby maps

Select Streaming world above. PHP reads the world bounds, preloads nearby maps and their shared assets, and releases distant maps. Use arrows/WASD to pan across the five sections, R to return, and X to retry a failed download. The status line lists ready maps. Watch the Network panel to see when each map downloads.

WorldStream API and lifecycle

Use the PHP engine

require 'autoload.php';

$loader = new PhpWasmEngine\Tiled\Loader;
$map = $loader->map('/assets/level.tmj');
$terrain = PhpWasmEngine\Physics\MapTerrain::build($map);
$movement = new PhpWasmEngine\Physics\Platformer($terrain);
$body = new PhpWasmEngine\Physics\Body(80, 100, 'runner');

See the README for the game loop, renderer, entities, asset formats, and collision model. Implementation notes cover texture arrays, isometric ordering, and continuous collision casts.
