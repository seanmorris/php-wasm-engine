A 2D game engine, written in PHP.

Load Tiled worlds, build entities from components, and run surface-based platforming in the browser.

Run PHP loads the runtime, intro cards, and title screen. Press Start / Enter, then choose Play.

Keyboard: arrows / WASD move · Space / Z jump · Down crouches · Tap Jump or hold X while crouching, then release Down to spindash · Hold X in air for drop dash · Jump again to glide or fly · Up / Down climb · R reset · P / Escape pause · F9 debug overlay. Open the pause menu to change Level or Movement. Level changes keep game time and settings; Movement updates the current player in place. Streaming world: arrows/WASD pan, R returns to the start, X retries failed downloads.

Gamepad: left stick / D-pad move and crouch · Tap A / Cross or hold B / Circle while crouching, then release Down to spindash · A / Cross jump · Start / Options pause · Back / Select reset. B / Circle retries downloads in Streaming world. Click the canvas and press a gamepad button to connect. Sticks use a 20% dead zone with proportional movement.

The game pauses in a hidden tab. If the browser releases WebGL, it restores graphics when the context returns and keeps the current game state. Release held gamepad buttons and center the sticks after returning to the game.

From loading screen to gameplay

Run PHP shows download progress, timed intro cards, and a scrolling title. Press Start, Enter, or click after the prompt appears to open the main menu. Choose Level and Movement, try the live Settings inputs, then Play. The selected level downloads on demand. During play, the pause menu can return here and retain the level for Resume game.

Edit examples/cards.php for card text and timing, or open examples/assets/title.tmj in Tiled to change the background layers. The title and main menu share the same parallax offset while gameplay time stays paused. Card API, example flow, and loading lifecycle

Collect rings without tunneling

The Platformer level promotes every animated Tiled tile with the ring class into a PHP entity. Run through one to remove its sprite and update the upper-left player HUD. SCORE, TIME, and RINGS use the same annotated bitmap font as the menus and follow moving-boxes-2's colored-label layout.

Pickup tests sweep the player's full movement path during each fixed update, so a fast actor cannot pass through a ring between frames. Teleports reset that sweep origin. The FPS readout stays separate at the lower left and no longer has a black background. Ring components and setup

Inspect a running game

Press F9 with the game focused, or turn on Settings → Debug overlay. The bitmap panel shows position, velocity, grounded state, surface angles, collision layer, camera, entity count, map loading, draw calls, tile uploads, and collision casts per frame. Speeds use pixels per second; angles use radians. World and isometric inspection scenes identify the camera view instead of showing an inactive player.

The unboxed lower-left FPS meter shows browser frames per second and average frame interval. Settings → FPS meter hides it independently. Both preferences survive level changes, and the overlay stays within the game canvas in fullscreen. Diagnostics and scripting

Recognize input sequences

Space and Xbox A share logical button 0. While playing, enter Up Up Down Down Left Right Left Right X Space, or use the D-pad followed by B A. Konami enables the debug panel. Its Sequence and Matches rows also report Down, Right, X, Down + C, and Space + X.

PHP observes fresh presses across keyboard and gamepad, with timing limits, held-button chords, charged releases, diagonals, and facing-relative directions for fighting-game combinations. Input API, bindings, and combo examples

Menus in PHP

Press P / Escape or Start / Options in a running demo. Break a block into sprites

Open the pause menu, then choose Level → Breakable blocks. Walking stops against a block; gain speed and hold Down to roll through it. At rest, hold Down to crouch and look lower after 0.75 seconds. Tap Jump / A / Cross for a discrete charge or hold X / B / Circle to build charge, then release Down to launch. Rolling contact shatters the block and preserves momentum. R or Back / Select restores all blocks. The three blocks split into 4 × 3, 2 × 8, and 8 × 2 grids. Their cropped shards move, spin, and fade while sharing the original sprite atlas.

An intact block has one sprite. After breaking, the same entity owns a SpriteGroup and loses its collision shape immediately. Open examples/assets/breakables.tmj in Tiled to change block sizes and the columns/rows properties. PHP API and lifecycle

Outline sprites

Sprites get a black outline one world pixel wide. It follows the image silhouette, including transparent gaps, and keeps its world-space thickness when you scale the artwork. Camera zoom scales the border on screen. The player uses this outline in the platformer demos; breakable boxes and their shards disable it.

$sprite->outline = false;

Set the flag on individual sprites or members of a SpriteGroup. They still share one atlas and one instanced draw. Collision bounds stay the same. Outline API

Stream nearby maps

Open the pause menu, then choose Level → Streaming world. PHP reads the world bounds, preloads nearby maps and their shared assets, and releases distant maps. Use arrows/WASD to pan across the five sections, R to return, and X to retry a failed download. The status line lists ready maps. Watch the Network panel to see when each map downloads.

Anchored backgrounds keep the same world offset as you cross map boundaries. PHP draws one background stack for the map at the camera center. Open examples/assets/stream.world in Tiled to edit the five sections.

Run a loop-de-loop

Choose Level → Loop-de-loop in the pause menu, then hold Right to build speed and run the loop. Hold Left after exiting to run it in reverse. The status line shows the selected collision layer. Losing speed on a wall or ceiling releases the character; jumping pushes away from the current surface.

Open examples/assets/loop.tmj in Tiled. The crown and floor are shared terrain. Layers 1 and 2 hold the two lower halves, and three layer-switch objects select the route. Collision layers do not change drawing order.

Use the PHP engine

require 'autoload.php';

$loader = new PhpWasmEngine\Tiled\Loader;
$map = $loader->map('/assets/level.tmj');
$terrain = PhpWasmEngine\Physics\MapTerrain::build($map);
$movement = new PhpWasmEngine\Physics\Platformer($terrain);
$body = new PhpWasmEngine\Physics\Body(80, 100, 'runner');

See the README for the game loop, renderer, entities, asset formats, and collision model. Implementation notes cover texture arrays, isometric ordering, and continuous collision casts.
