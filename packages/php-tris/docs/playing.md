# Playing and scoring

Use Left/Right to move, Down to soft drop, Up/X or Z to rotate, Space to hard drop, and C/Shift to hold. Escape or P pauses. Controller A/B rotate, X hard drops, and Y holds. Touch controls appear on touch devices.

Solo modes share the same board, active piece, preview queue, hold slot, line clearing, and level progression. Their scoring rules vary by objective, but all updates occur on the fixed simulation clock and render independently at the display rate.

The title and pause menus use the same named input actions as gameplay. A fresh-press guard prevents the button that starts a run from immediately rotating or dropping its first piece.
