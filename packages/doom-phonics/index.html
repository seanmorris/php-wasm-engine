PHONICS / PLAY

Doom-Phonics

A native WAD adapter, DECORATE-driven ECS, and direct GLES renderer running Episode 1 data.

Choose a world to begin.

Controls

W/S move, A/D strafe, arrow keys turn, E or right click uses, and Space or left click fires. Number keys select weapons. Click the arena for mouse look; Escape releases the pointer and P pauses.

WAD Stack opens the reusable game launcher. All archives share one top-to-bottom load order, later files override earlier files, and the selected map can come from any file in the stack. This allows one complete archive to supply an Episode map while a later archive contributes weapons and other assets. Online Play enters a Matrix chat lobby; Game settings opens the launcher over chat before a player offers or accepts a match. Each player supplies locally owned files; only safe names, profiles, sizes, digests, ordering, and the selected map are exchanged.

Sign in with Matrix opens the selected homeserver's OAuth page. Doom-Phonics does not request a Matrix password. The repository demo uses the original shareware IWAD only as local reference material. Published Doom-Phonics packages provide the adapter and game systems; worlds provide their own licensed data.
