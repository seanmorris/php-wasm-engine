# PHP Buster

PHP Buster is a deterministic PHP and Phonics port of **Blockade Buster**. It keeps the original arcade wave sequence and scoring balance while using a 60 Hz fixed simulation, interpolated rendering, editable keyboard and controller bindings, mouse and touch movement, and a browser-local top-ten table.

## Play

Load `worlds/buster.world` with the Phonics launcher. Move with the arrow keys, WASD, controller left stick, mouse, or touch drag. Hold Space, the primary mouse button, A, or RB to fire. Pause with Escape, P, or Start.
