# Quickstart — drafting outline

I. Define the result and prerequisites
    A. Create an independent movable-player game
    B. Obtain Node, Tiled, the Phonics artifact, and a matching runtime
II. Create the game package
    A. Bootstrap the CLI from the packed artifact
    B. Install the CLI locally in the new package
    C. Identify the files the author will edit
III. Play the world
    A. Start the generic preview with an explicit runtime
    B. Verify movement and explain server lifetime
IV. Explain the starter’s Entity Component System
    A. Define entities, components, and systems with concrete starter examples
    B. Trace map objects through factories into live registry state
    C. Explain component queries, simulation time, and rendering
    D. Extend with focused systems and explicit ordering dependencies
V. Change the game in Tiled
    A. Move the Player object and increase its speed
    B. Refresh integrity, validate, and reload
VI. Change its PHP rendering
    A. Change the player color without changing the host
    B. Declare new files before hashing or building
VII. Build a distributable package
    A. Verify the world and build declared files
    B. Preview the build and pack it without publishing
    C. Point to package, module, and Tiled guides
