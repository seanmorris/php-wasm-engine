# Phonics documentation — site drafting outline

I. Introduce Phonics and get a game running
    A. Explain the world-first model (index)
        1. Tiled describes composition
        2. Packages supply behavior
        3. PHP and SDL run the session
    B. Build a first game through a guided tutorial (quickstart)
        1. Bootstrap a package and preview its world
        2. Explain entities, components, factories, and systems
        3. Edit its map, speed, and PHP rendering
        4. Validate and package the result
    C. Install and run locally (install)
        1. Create independent game packages with the CLI (cli)
    D. Explore the independent games (games)
        1. Play Sane-Phonics in the shared site shell
        2. Play PHP-Noid in the shared site shell
        3. Play PHPTris with keyboard, controller, or touch
II. Author a world
    A. Declare and load a world (worlds)
    B. Import packages and place entities in Tiled (tiled)
    C. Preserve resource identity through relocation (resources)
III. Extend the framework
    A. Register modules, systems, and factories (modules)
    B. Declare exports, dependencies, and integrity (packages)
IV. Consult detailed references
    A. Framework architecture (architecture)
    B. Input and sequences (input)
    C. ECS performance and measurements (performance)
    D. Browse the complete programming API (api)
        1. PHP classes, methods, public state, and compatibility aliases
        2. Browser entry points, module context, and lifecycle services
V. Maintain and distribute
    A. Build, verify, and edit the framework and documentation (contributing)
    B. Prepare artifacts and smoke-test publication (release)

Each page has a separate Harvard outline in this directory. The outlines are drafting tools; the published site uses plain headings and navigation.
