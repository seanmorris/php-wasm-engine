# Contributing — Harvard drafting outline

Reader: a contributor changing Phonics, an example game, or the documentation.
Outcome: locate the source of truth, build the relevant output, and run focused checks.

I. Set up the framework checkout
    A. Install development/build prerequisites
    B. Start the runtime and development site
II. Locate editable sources
    A. Distinguish framework files from the examples checkout
    B. Select a local examples checkout for documentation builds
    C. Identify authored pages, imported references, and game chapters
III. Regenerate manifests after executable/resource changes
    A. Use repository manifests for the framework
    B. Use package integrity for independent games
IV. Run focused checks and build documentation
    A. List native, browser, editor, and artifact checks
    B. Distinguish text-only site build from full runtime/game build
    C. Explain static serving and deployment prefixes
V. Maintain clear documentation
    A. Draft a Harvard outline before reorganizing or writing
    B. Match headings to reader tasks and preserve old links
    C. Edit source files, rebuild, and check navigation/links
