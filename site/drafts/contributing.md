# Contributing — drafting outline

I. Identify the audience
    A. Framework, bundled-demo, and documentation contributors
    B. Direct game authors to the public CLI workflow
II. Set up the repository
    A. Install source dependencies and the pinned runtime
    B. Run the demo and editor integration
III. Regenerate repository manifests
    A. Use the aggregate npm command for repository-owned packages
    B. Commit manifests with their source changes
IV. Verify changes
    A. Run relevant PHP, browser, editor, and CLI suites
    B. Check independently packed artifacts
V. Build and maintain documentation
    A. Use the pinned smgen revision
    B. Publish a static tree with a configured URL prefix
    C. Maintain drafting outlines and source reference chapters
