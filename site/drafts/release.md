# Release a package — drafting outline

I. Prepare the author's distribution
    A. Refresh hashes and validate the world
    B. Build declared files and inspect the packed artifact
II. Verify an independent consumer
    A. Install without workspace symlinks
    B. Test input, lifecycle, and dependencies
III. Publish separately
    A. Use the author's normal release process
    B. Keep versions immutable across npm and Composer
IV. Verify CDN composition
    A. Configure host policy and import the published manifest in Tiled
    B. Exercise cross-origin dependencies and relocation
