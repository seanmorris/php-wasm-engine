# Paths and shared assets — Harvard drafting outline

Reader: a package author diagnosing a path, duplicate asset, or ownership problem.
Outcome: predict the resolved path and understand when loaded bytes can be released.

I. Resolve a path relative to its source document
    A. Walk through one world, map, tileset, and image example
    B. Provide the complete declaring-document table
II. Refer to an exported package item
    A. Decode @arcade/game into alias and export
    B. Give its explicit manifest URL equivalent
    C. Name the PHP and browser resolution APIs after the example
III. Share bytes while keeping placements independent
    A. Explain canonical identity and versioned URLs
    B. Show two map placements with separate state
    C. Describe ownership release and runtime code lifetime
IV. Direct advanced use to the ordered-file guide
    A. Preserve the old resource-stack fragment
    B. Link to the separate declaration and multiplayer requirements
